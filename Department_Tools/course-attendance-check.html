Attendance Check

This report checks the Attendance tool in each of your Brightspace course offerings. It reads the course offerings attached to your account, so it covers the sections you are enrolled in for the terms you pick — not every section in a term. For each section it opens the Attendance tool, reads each register and its session count, and, when you ask it to, opens each register's data to see whether attendance has actually been marked. Every section gets one status.
